## Улучшенная модель адаптивного порога

### Кусочно-линейная модель
threshold(speed) =
0.15° if speed ≤ 60
0.15 + (speed-60)×0.008 if 60 < speed ≤ 90
0.39 + (speed-90)×0.06 if speed > 90



### Проверка

| Speed | Threshold | Avg\|err\| | Запас |
|-------|-----------|------------|-------|
| 60    | 0.15° | 0.047° | 3.2x |
| 80    | 0.31° | 0.085° | 3.6x |
| 90    | 0.39° | 0.19°  | 2.1x |
| 100   | 0.99° | 0.37°  | 2.7x |
| 110   | 1.59° | 0.76°  | 2.1x |
| 120   | 2.19° | 2.10°  | 1.04x ⚠️ |

### Рекомендации

- **speed ≤ 100** — адаптивный порог работает надёжно.
- **speed 100–110** — работает, но запас меньше.
- **speed > 110** — не рекомендуется для коллаборации.
