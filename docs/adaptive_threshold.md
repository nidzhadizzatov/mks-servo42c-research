# Адаптивный порог + Settle Time

## Проблема

При использовании **фиксированного порога** (0.4°) и **отъезда** (retreat):
- Мотор при отъезде теряет позицию.
- Ошибка временно подскакивает до 0.3–0.5°.
- Это вызывает **новое ложное срабатывание**.
- **Каскадный эффект:** 144 срабатывания за 60 секунд без касания.

## Решение

### 1. Адаптивный порог
threshold(speed) =
0.15° if speed ≤ 60
0.15 + (speed-60)×0.008 if 60 < speed ≤ 90
0.39 + (speed-90)×0.06 if speed > 90
