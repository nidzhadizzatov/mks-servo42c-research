# MKS SERVO42C Research

Исследование обнаружения столкновений и адаптивного управления замкнутым шаговым двигателем MKS SERVO42C через UART.

## Статус

🚧 В разработке — Шаг 1: инициализация проекта.

## Структура

- `include/` — заголовочные файлы
- `src/` — исходники
- `examples/` — примеры использования
- `tests/` — тесты
- `docs/` — документация
- `data/` — экспериментальные данные
- `tools/` — вспомогательные скрипты
